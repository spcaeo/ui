The grid

Zero dependencies. The filter menus are native popovers, not a library.

Inheriting a host design system

The same component, unmodified, inside an element that defines shadcn/ui's CSS variables. It imports nothing from the host — it just reads the tokens if they are there, so it cannot duplicate or collide with anything.

The states are not interchangeable

A failed request is not a count of zero, and "nothing matched your filter" is not "nothing exists". Collapsing these into one card is the most common grid bug there is.
